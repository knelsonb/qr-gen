  About, privacy and security
  
      Everything on this page runs in your browser. The text you type, the codes you make and any logo you choose are never sent anywhere. Once loaded, the only requests the page makes are for its own files from this site, so it can work offline; it sets no cookies and has no analytics, ads or third-party code. You can check this in your browser's developer tools, or go offline and keep using it.
      
  
      The host, Cloudflare, sees ordinary connection logs when you load the page, like any website. Your style settings, colours, border and the like, are kept on this device once you change them so they are there next time, and so is the count of codes you have made here. The content of a code and its caption are never kept. .
      
  
      Links with settings in them can pre-fill this page, so look at what the code contains before you print or share it. The page warns about link shapes that are commonly abused, but a warning is a hint and does not prove a link safe.
      
  
      A printed code is permanent. This page makes plain codes that hold their content directly, so there is nothing to expire and no one is told when it is scanned.
      
  
      Keyboard: Ctrl+S saves a PNG, Ctrl+P prints, Ctrl+Shift+C copies the image.
      
  
      The source is short and public: github.com/knelsonb/qr-gen. To report a vulnerability, see security.txt.
